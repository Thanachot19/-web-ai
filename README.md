# 🎯 Web Presentation: การเลือกใช้ AI ตามหลักการในสไลด์ & 4 สถานการณ์จริง

> **บทที่ 3 การเปรียบเทียบโมเดล AI และสถาปัตยกรรมของโมเดลภาษา**  
> รายวิชา: **21909-2009 การใช้งานแอปพลิเคชันปัญญาประดิษฐ์**

เว็บนำเสนอข้อมูลระดับมืออาชีพ (Interactive Web Presentation) ที่ถูกออกแบบมาสำหรับการเปิดนำเสนอหน้าห้องเรียน ห้องประชุมสัมมนา หรือใช้ประกอบการอธิบายเนื้อหาจริง โดยสร้างขึ้นด้วย **HTML5, CSS3 และ JavaScript (Vanilla ES6+)** ภายใต้มาตรฐานการแสดงผลอัตราส่วน **16:9** รองรับทั้งจอโปรเจกเตอร์ คอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน

---

## 🌟 จุดเด่นและฟีเจอร์ของระบบนำเสนอ

1. **สถาปัตยกรรม 16:9 มาตรฐานห้องประชุม (Widescreen Presentation)**  
   จัดวางองค์ประกอบให้พอดีกับจอภาพอัตโนมัติ ไม่ตกขอบและไม่ยืดหดผิดสัดส่วน
2. **ระบบนำทางครบวงจร (Full Presentation Navigation)**  
   - ปุ่ม Previous / Next และ Progress Bar แสดงความคืบหน้าแบบ Real-time
   - รองรับคีย์บอร์ดสากล: `Arrow Left / Right`, `Spacebar`, `Home / End`
   - ระบบ **Touch Swipe Gestures** ปัดซ้าย-ขวาบนจอสัมผัส/มือถือ
   - โหมด **Fullscreen Presentation (ปุ่ม F)**
3. **สลับโหมดสว่าง / โหมดมืด (Dark & Light Theme Mode - ปุ่ม T)**  
   รองรับการเปลี่ยนธีมภาพให้เหมาะสมกับสภาพแสง ทั้งการเปิดในห้องประชุมมืดด้วยจอโปรเจกเตอร์ หรือห้องสว่างด้วยจอคอมพิวเตอร์ทั่วไป โดยจดจำการตั้งค่าไว้ในเครื่องอัตโนมัติ
4. **4 ปุ่มหัวข้อ Interactive บนหน้าปก (Slide 1 Jump Chips)**  
   ปุ่มชิปทั้ง 4 บนหน้าแรกสามารถคลิกเพื่อกระโดดข้ามไปยังสไลด์เฉลยและวิเคราะห์ของแต่ละหัวข้อได้ทันที
5. **สารบัญสไลด์ทั้ง 18 สไลด์ (Overview Grid Modal - ปุ่ม O)**  
   เปิดดูตารางสไลด์ทั้งหมดแบบการ์ด เพื่อคลิกข้ามไปยังสไลด์ที่ต้องการได้ทันทีโดยไม่ต้องกดเลื่อนทีละหน้า
6. **โน้ตสำหรับผู้บรรยาย (Presenter Notes Drawer - ปุ่ม N)**  
   มีบทสรุปคำพูด (Speaker Script) สำหรับผู้บรรยายในทุก ๆ สไลด์ ช่วยให้การนำเสนอเป็นมืออาชีพและราบรื่น
7. **Interactive AI Decision Simulator & Live Cost Calculator (สไลด์ที่ 16)**  
   เครื่องมือคำนวณและจำลองการตัดสินใจเลือกโมเดล พร้อมคำนวณต้นทุนต่อครั้ง (USD & บาท) แบบ Real-time ตามสูตรราคาจริงในสไลด์
8. **Thai Tokenizer Comparison Visualizer (สไลด์ที่ 9)**  
   แสดงการเปรียบเทียบการตัดคำและจำลองอัตราการบวมของ Tokenizer ภาษาไทย (Thai Token Inflation 2–4 เท่า)
9. **ระบบเล่นสไลด์อัตโนมัติ (Autoplay Kiosk Mode - ปุ่ม P)**

## 🧭 สรุปการแก้โจทย์ 4 สถานการณ์จริง (The 4 Real-World Challenges)

| สถานการณ์ | ความท้าทายหลัก | ระดับโมเดลที่แนะนำ (Tier) | โมเดลที่แนะนำ | เหตุผลเชิงสถาปัตยกรรม & ต้นทุน |
| :--- | :--- | :--- | :--- | :--- |
| **1. สรุปอีเมล 2,000 ฉบับ** | ข้อมูลปริมาณมหาศาล (1M+ Token), งบประมาณบานปลาย | **รุ่นเล็ก (Fast / Nano)** | **Gemini 3.1 Flash / GPT-6 Luna** | งานสรุปสั้นไม่ต้องการตรรกะซับซ้อน การใช้ Flash ประหยัดกว่าโมเดลเรือธงถึง **66 เท่า** ($0.18 vs $12.50) ลดต้นทุนได้ 60–80% ตามกฎทอง พร้อมใช้ Batch API |
| **2. วิเคราะห์โค้ด 500 บรรทัด** | ต้องการความถูกต้องสูงสุด ผิดพลาดไม่ได้ (Zero Tolerance) | **เรือธง (Flagship) / Reasoning** | **Claude Sonnet 5.5 / DeepSeek R-series** | โค้ดต้องการการคิดเชิงเหตุผล (Chain of Thought) ป้องกันบั๊กและช่องโหว่ Token น้อย (30K) ต้นทุนเพียง 4 บาท แต่ช่วยป้องกันความเสียหายระดับแสนบาท |
| **3. ตอบแชทลูกค้าภาษาไทย** | ต้องการความเร็วโต้ตอบสูง (TTFT ต่ำ), เข้าใจภาษาพูดไทยแท้ | **โมเดลไทยเฉพาะทาง / Fast Model** | **Typhoon (SCB 10X) / Gemini Flash** | ลูกค้ารอไม่ได้ ห้ามใช้ Reasoning model โมเดลไทยตัดคำแม่นยำ ช่วยลดปัญหา Tokenizer ภาษาไทยบวม 2-4 เท่า และเข้าใจสำนวนไทยเป็นธรรมชาติ |
| **4. ข้อมูลลูกค้าลับ & PDPA** | ความเป็นส่วนตัว ห้ามข้อมูลรั่วไหลออกนอกองค์กร 100% | **โมเดลเปิด (Open Weights - On-Premise)** | **Llama 3.3 / DeepSeek V3 / Qwen 2.5** | ดาวน์โหลดน้ำหนักมารันบน Server ภายใน (Air-gapped) ข้อมูลไม่ออกเน็ต 100% สอดคล้องตาม PDPA และไม่มีค่าใช้จ่ายต่อ Token (Zero Token Cost) |


## ⌨️ คีย์ลัดสำหรับการควบคุมสไลด์ (Keyboard Shortcuts)

| ปุ่มคีย์บอร์ด | การทำงาน |
| :--- | :--- |
| <kbd>→</kbd> หรือ <kbd>Space</kbd> หรือ <kbd>PageDown</kbd> | ไปยังสไลด์ถัดไป |
| <kbd>←</kbd> หรือ <kbd>Shift</kbd> + <kbd>Space</kbd> หรือ <kbd>PageUp</kbd> | ย้อนกลับไปสไลด์ก่อนหน้า |
| <kbd>Home</kbd> | ไปยังสไลด์แรก (Title Slide) |
| <kbd>End</kbd> | ไปยังสไลด์สุดท้าย (Q&A) |
| <kbd>F</kbd> | เปิด / ปิด โหมดเต็มหน้าจอ (Fullscreen) |
| <kbd>T</kbd> | สลับโหมดสว่าง / โหมดมืด (Toggle Light / Dark Theme) |
| <kbd>O</kbd> | เปิดสารบัญสไลด์ทั้งหมด (Overview Thumbnails Grid) |
| <kbd>N</kbd> | เปิด / ปิด โน้ตผู้บรรยาย (Speaker Notes Drawer) |
| <kbd>P</kbd> | เริ่ม / หยุด การเล่นสไลด์อัตโนมัติ (Autoplay 12 วินาที/สไลด์) |
| <kbd>?</kbd> | ดูหน้าต่างรวมคีย์ลัดช่วยเหลือ |
| <kbd>Esc</kbd> | ปิดหน้าต่างป๊อปอัปทั้งหมด |

## 🚀 วิธีเปิดใช้งาน

1. **เปิดผ่านเบราว์เซอร์ปกติ:**
   - ดับเบิลคลิกเปิดไฟล์ `index.html` หรือ `presentation_single_file.html` ผ่าน Google Chrome, Microsoft Edge, Safari หรือ Firefox
2. **การนำเสนอบนหน้าจอโปรเจกเตอร์:**
   - กดปุ่ม <kbd>F</kbd> เพื่อเข้าสู่โหมดเต็มหน้าจอ (Fullscreen Mode)
   - กดปุ่ม <kbd>N</kbd> หากต้องการดูบทบรรยายประกอบสไลด์
3. **การใช้งานแบบออฟไลน์ 100%:**
   - ไฟล์ `presentation_single_file.html` สามารถคัดลอกใส่แฟลชไดรฟ์หรือส่งทางอีเมล และเปิดใช้งานได้ทันทีโดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต
